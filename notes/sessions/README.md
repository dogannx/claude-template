# Session Notes

One file per work session: `YYYY-MM-DD-<slug>.md`. Created at session end via
`/session-end`, based on `.claude/templates/session-template.md`.

## Why

- Picks up exactly where you left off next time.
- A searchable record of what happened and why, between full ADRs and raw git history.
- Lets an AI assistant reconstruct context quickly.

## Guidelines

- Keep them concise and high-signal — decisions and next steps matter most.
- Promote durable decisions to an ADR; promote tasks to `todo/`.
- Don't delete old notes; they are cheap history.

See `2026-06-11-example.md` for the shape.
