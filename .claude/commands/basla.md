# /basla — Start the session

Tetikleyiciler: **"başlayalım"**, **"neredeyiz"**, **"durum ne"**, **"kaldığımız yer"**,
**"bugün ne yapıyoruz"**.

1. `memory/` (4 dosya) — güncel proje gerçeklerini oku.
2. `notes/progress.md` — nerede kaldık.
3. `todo/TODO.md` — aktif görevler.
4. `notes/sessions/` içindeki en son notu oku.
5. `git status` + `git log --oneline -10`.

Sonra kısa brifing ver:
- **Neredeyiz:** 2–3 cümle.
- **Bugünün önerilen odağı:** en önemli 1–3 görev, gerekçesiyle.
- **Açık sorular / engeller:** başlamadan karar vermem gereken belirsizlikler.

Odağı **ben onaylamadan** kod yazmaya başlama.
